# QuestForge Benefit Map

The core IP: how a **help-target** (read from Telos) becomes a **game mechanic**. Used in the PRESCRIBE step.
Read a confirmed help-target, find its row, pick the mechanic, then pick an archetype (`References/Archetypes.md`)
and an honest claim (`References/Evidence.md`).

## Telos file → design role

| Telos file(s) | Role in the game design |
|---|---|
| `GOALS` | Win conditions / the real-world outcome the game drives toward |
| `PROBLEMS`, `CHALLENGES` | Candidate **help-targets** (handle PROBLEMS sensitively) |
| `STRATEGIES` | Existing approaches the game should reinforce, not contradict |
| `BELIEFS`, `WRONG`, `FRAMES`, `MODELS` | Reframing targets (limiting beliefs, mental models to install) |
| `NARRATIVES` | Self-story → identity arc / avoidance patterns |
| `MISSION` | North-star theme & the ultimate "epic win" |
| `BOOKS`, `MOVIES` | **Aesthetic, genre, tone — the engagement skin** |
| `WISDOM`, `LEARNED` | Content for knowledge/reframe mechanics; values to reinforce |
| `PROJECTS` | Real-world quests to gamify directly |
| `PREDICTIONS` | Optional seed for forecasting/strategy mechanics |
| `TRAUMAS` | **Excluded by default** — never theme/antagonist; opt-in "gently avoid" only |
| `TELOS` | Framework / overview context |

## Mechanism → mechanic → Telos signal → evidence anchor

| Benefit category | Change mechanism | Game mechanic | Telos signal that triggers it | Evidence anchor | Transfer confidence |
|---|---|---|---|---|---|
| **Behavioral** | Habit formation | Living-world responding to a logged real habit; streaks w/o shame | recurring behavior in GOALS/STRATEGIES; inconsistency in PROBLEMS | Fogg B=MAP; habit loop; SuperBetter | **High** |
| **Behavioral** | Commitment / implementation intentions | "If-X-then-Y" quest cards w/ witness + stake | stalled GOALS/PROJECTS | Gollwitzer | **High** |
| **Emotional** | Graded exposure | Self-paced micro-dare ladder in a safe space | avoidance/anxiety in CHALLENGES/NARRATIVES | CBT exposure; MindLight RCT | **Med-High** |
| **Emotional** | Mood regulation / rumination-interrupt | Short bounded high-absorption flow puzzle | stress/low-mood/rumination in PROBLEMS | Tetris/Holmes; Flow | **Med** |
| **Mindset** | Cognitive reframing | Coach an NPC carrying YOUR limiting belief (self-distancing) | WRONG/BELIEFS/FRAMES | SPARX; self-distancing research | **Med-High** |
| **Mindset/Social** | Self-efficacy ("epic wins") + accountability | Real acts toward MISSION unlock in-game epic wins; ally guild | low self-efficacy in NARRATIVES; MISSION | McGonigal; SDT relatedness | **Med** |
| **Cognitive** | Skill rehearsal | Adaptive-difficulty drills tuned to flow | named skill gap in PROBLEMS | EndeavorRx; deliberate practice | **Low transfer** → claim only the trained skill |
| **Cognitive** | Knowledge / retrieval | Spaced-repetition fused as world-decay/retrieval | GOALS/PROJECTS needing a domain | Ebbinghaus; retrieval practice | **Med** (domain-specific) |
| **Social** | Connection / relatedness | Co-op / shared-goal guilds | loneliness in PROBLEMS; connection GOALS | SDT relatedness | **Med** |

## Two checks on every prescription

1. **SDT check** — does the mechanic satisfy **autonomy** (player sets pace/choices), **competence** (clear,
   achievable mastery), **relatedness** (optional social tie)? If none, redesign.
2. **Fogg check** — is the real-world target a **tiny, prompted, high-ability** action? If it needs high
   motivation to start, shrink it.

## Bias rule

Prefer **Behavioral / Emotional / Mindset / Social** targets (outcomes transfer). Treat **Cognitive**
"brain-training" as lowest-confidence: only when the user explicitly wants skill drilling, and always with the
transfer caveat (`References/Evidence.md` §3).
