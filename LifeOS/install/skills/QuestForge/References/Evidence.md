# QuestForge Evidence Base & Honesty Rules

The design rests on real serious-games and behavior-change science. Use this file to (a) pick mechanics that
actually work, and (b) write **honest claims**. The single most important rule is the transfer caveat in §3.

## 1. Exemplars (real products, evidence status)

| Game | What it does | Evidence status |
|------|--------------|-----------------|
| **EndeavorRx** (Akili, AKL-T01) | Action game targeting attentional control for pediatric ADHD | **Strongest.** First FDA-cleared (De Novo, 2020) game therapeutic. STARS-ADHD RCT n=348, *Lancet Digital Health* 2020 — improved objective attention. Real-world transfer modest. |
| **SPARX** (Merry et al.) | 3D fantasy game delivering CBT for adolescent depression | **Strong.** RCT *BMJ* 2012, n=187 — non-inferior to treatment-as-usual; remission ~44% vs 26%. |
| **Tetris** (Holmes/James) | Played in the consolidation window to block trauma intrusive memories | **Robust mechanism, narrow scope.** *PLOS ONE* 2009/2010; ER RCT *Molecular Psychiatry* 2017 cut intrusive memories. Not a full PTSD treatment. |
| **Re-Mission** (HopeLab, Kato) | Shooter destroying cancer cells; boosts treatment adherence | **Strong.** RCT n=375, *Pediatrics* 2008 — better adherence, knowledge, self-efficacy. Changes *behavior*. |
| **SuperBetter** (McGonigal) | Gameful resilience app (quests/power-ups/bad-guys) | **Moderate.** UPenn RCT 2015 — reduced depression/anxiety, raised optimism. Small/self-report. |
| **MindLight** (Schoneveld) | Biofeedback game for child anxiety | **Moderate.** RCT — non-inferior to CBT. |
| **Lumosity** (Lumos Labs) | 40 "brain-training" mini-games | **Cautionary tale.** **FTC $2M settlement, 2016** for deceptive ads ("preyed on fears" without science). The anti-pattern. |

## 2. Behavior-change & engagement frameworks (goal → mechanic lenses)

- **Self-Determination Theory** (Deci & Ryan) — satisfy **autonomy, competence, relatedness**. The primary lens:
  check every concept against the three needs.
- **Flow** (Csikszentmihalyi) — match challenge to skill; use dynamic difficulty.
- **Fogg Behavior Model — B = MAP** (Motivation × Ability × Prompt). Design the target as a *tiny, prompted,
  high-ability* action.
- **Implementation intentions** (Gollwitzer) — "if-situation-X-then-action-Y"; strong effect size. Encode as
  in-game commitments (see archetype *The Pact*).
- **Habit loop** (cue → routine → reward; Duhigg/Wood) — variable reward builds automaticity (avoid compulsion).
- **Spaced repetition** (Ebbinghaus) — schedule re-exposure for learning/retention loops.
- **Octalysis** (Chou) / **HEXAD user types** (Marczewski) — tailor mechanics to motivational type.

## 3. The transfer caveat (THE honesty constraint)

**Trained-task gains rarely transfer to general cognition or daily life.**
- **Owen et al. 2010** (*Nature*, n=11,430): every trained task improved; **zero transfer** to untrained tasks.
- **Stanford Center on Longevity + Berlin Max Planck 2014** (~70 scientists): "no compelling evidence" brain
  games improve general cognition; claims "frequently exaggerated and misleading."
- **Simons et al. 2016** (*PSPI*): brain training is not a scientifically grounded way to improve cognition.

**Implication for QuestForge:** never promise "smarter/sharper brain." For a cognitive concept, claim ONLY the
specific trained skill ("practices N-back-style updating"), and prefer steering the user toward a
**behavioral / emotional / mindset / social** target, where real-world outcomes are achievable (Re-Mission,
SPARX, SuperBetter all changed behavior/mood, not general intelligence).

## 4. Serious-games design principles (helpful game vs generic gamification)

1. **Bake the active ingredient INTO the core loop** — EndeavorRx's adaptive algorithm *is* the gameplay;
   Tetris's visuospatial load *is* the intervention. A points wrapper around a worksheet fails.
2. **Intrinsic > extrinsic.** Over-reliance on points/badges/leaderboards undermines SDT (over-justification
   effect once rewards stop). Gate extrinsic rewards.
3. **No dark patterns** — no exploitative variable reward, FOMO streaks, or pay-to-progress in a wellness tool.
4. **Honest, matched claims** — claim only what the chosen mechanism evidences; add the transfer caveat for
   cognitive concepts; wellness framing, not medical.
5. **Fidelity + measurement** — keep the real active ingredient (e.g. genuine CBT in SPARX) and attach one
   measurable outcome per concept (the one-pager's "measurement hook").

## 5. The honest-claim line (template for every one-pager)

> "Designed to **{trains skill X / supports behavior Y / aids mood Z}** through {mechanism}. This is a wellness/
> engagement tool, **not a clinical treatment**.{ If cognitive: ' Trained-game gains often don't transfer to
> general ability.'}"
