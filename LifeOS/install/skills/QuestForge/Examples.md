# QuestForge — Worked Examples

Synthetic personas only — never embed a real user's data in this public skill.

## Example A — targeted help (full GenerateGame pipeline)

**Synthetic Telos "Sam":** GOALS: *run a 5k, speak at a meetup*; PROBLEMS: *avoids public speaking,
procrastinates*; BOOKS/MOVIES: *Dune, The Expanse*; MISSION: *become a confident communicator*.

- **READ** → Telos loaded (TRAUMAS excluded by default).
- **INFER** → candidate help-targets:
  1. public-speaking avoidance — *emotional / graded exposure* — quote: "avoids public speaking" — **High**
  2. procrastination on goals — *behavioral / commitment* — quote: "procrastinates" — **High**
  3. (no cognitive/memory signal — not proposed)
- **CONFIRM** → Sam picks #1. (If Sam had said "just make something fun," we'd switch to QuickConcept.)
- **PRESCRIBE** → emotional / **graded exposure**; archetype **Threshold**; evidence anchor: CBT exposure +
  MindLight RCT. Honest claim: *"builds tolerance for speaking up via graded practice — a wellness tool, not a
  treatment."*
- **EXTRACT INTERESTS** → from Dune/Expanse → hard-sci-fi, station/fleet setting, terse military tone.
- **GENERATE → one-pager:**

```
# Airlock — a hard-sci-fi game to build tolerance for speaking up
- Help-target: public-speaking avoidance ("avoids public speaking")   Benefit: Emotional   Confidence: Med-High
- Active ingredient: graded, self-paced exposure                       Archetype: Threshold
- Core loop: You're a station officer who voice-logs transmissions on widening channels — empty channel → a
  friend → a duty crew → the whole fleet. Each "airlock" you cycle is one rung harder. You set the pace;
  depressurizing (retreat) is always safe and never a failure.
- The skin: Dune/Expanse — terse comms, station hum, fleet politics as the "audience."
- First session (B=MAP tiny action): record one 10-second transmission to an empty room.
- Honest claim: "Builds tolerance for speaking up via graded practice. A wellness/engagement tool, not a
  clinical treatment."
- Measurement hook: highest channel rung reached per week.
- Build path: analog (a dare-ladder card deck) playable today, or minimal digital (mic + tiers). Feasibility 4/5.
- Scores: benefit-fit 5 · evidence 4 · engagement 4 · resonance 5 · feasibility 4
```

## Example B — the working-memory case, handled honestly

**Synthetic "Lee":** PROBLEMS: *"terrible working memory, lose my train of thought"*; BOOKS: *Tolkien*.

- The obvious move is a memory-trainer. **Evidence check (`References/Evidence.md` §3):** cognitive transfer is
  weak — do not promise "better memory."
- **CONFIRM** offers Lee a choice: (a) a genuine working-memory *practice* game with an honest caveat, or (b)
  pivot to a **behavioral** target ("lose my train of thought" in meetings → a note-taking habit game, which
  transfers).
- If Lee insists on (a): archetype **The Cartographer**, themed in Middle-earth — redraw a self-erasing map of a
  shifting realm. Honest claim: *"Practices working-memory updating in-game. Note: trained-game gains often
  don't transfer to everyday memory (Owen 2010; Simons 2016)."* Measurement hook: max map complexity held.

**Lesson:** QuestForge does not refuse the user's framing — it serves it *and* tells the truth, and offers the
higher-transfer alternative.
